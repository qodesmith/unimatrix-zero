# 18. Offline, reconnect and error states

Source: [Reconnect, offline and error states](https://github.com/qodesmith/unimatrix-zero/issues/40) (prototype, variant A), [Provider drivers, process model and IPC event list](https://github.com/qodesmith/unimatrix-zero/issues/38) (amended).

- **Bands across the top of the canvas** for problems affecting the whole app or a whole Provider: offline, an expired sign-in, a Provider program that will not start, an outage, a failed update, low disk, a crash. Worst first, each with one action, overlaying the canvas so nothing jumps.
- **No offline queue.** Offline, Send is off, the draft is kept ("Offline · sending waits for the connection"), and deleting still works. **A refused send adds nothing to the Tree**: the Prompt stays in the Input and the band says why ("Sign in again", "Download Claude again"). While a Provider host restarts, Send is off until it reports ready; the app never holds a Prompt and sends it later by itself.
- **Cut-off Replies** keep their text ("reconnecting…" then "Connection lost") and are never retried by the app ([§7](./07-replies.md)).
- **Sign-in expiry** is expected roughly every 4 weeks on Claude. "Login expired" and "token revoked" become the reconnect band; "Sign in again" opens a dialog with the onboarding steps; signing in as a different account simply continues the existing Trees. Refreshing stays with the vendor programs; the app only sees signed in or out, never runs `claude auth status` on a timer or throwaway sessions, and closes `claude` processes gracefully.
- **A broken Provider program:** "Download Claude again" with "Downloading Claude… N%"; if a fresh copy still fails, "Report a problem…". **A failed update** says it "didn't finish downloading" or "didn't pass its safety check", that the current version still works, and offers Try again.
- **Settings → Connections:** **Sign out** ("Ends your sign-in. Claude stays set up; sign in again to pick up where you left off."; asks first only while Replies run) and **Remove Claude…** ("Removes Claude from this app. Your Trees stay. You can download Claude again later."; always asks, shows how many Replies are running, stops them with "Stopped: you removed Claude", cancels any download, deletes the sign-in data and the vendor program, and returns the card to Connect). "Disconnect" is not a word the app uses.
