# 2. Scope

**In v1:** Claude and ChatGPT; canvas mode and chat mode on one Tree; Mac, Windows and Linux; attachments; Workspaces (files the AI edits, app-owned or a linked folder, with Snapshots per Reply); Subagents; MCP servers, Skills and Plugins; Summaries; Export, Archive and restore; full-text search; usage display; Themes (format, built-ins, import/export); Reports.

**Out of scope** (ruled out on the map; a redraw of the destination is a new effort):

- Syncing across devices, any cloud backend, user accounts
- Importing conversations from other apps (Claude.ai, ChatGPT, Claude Code)
- Sharing Trees with other people
- Merging Branches (the AI can combine Branches' files through a Prompt; the Tree stays a tree)
- Providers beyond Claude and ChatGPT
- Mobile; app store distribution
- Kid-specific or parental features
- Regenerate as a sibling Reply; editing a sent Prompt (delete and prompt again)
- Interface languages other than English
- Multiple accounts per Provider, or switching accounts
- Exposing Branches as real git branches in a linked repo
- Automatic archiving or reminders to archive; merging a restored Tree with an existing one or keeping both copies
- Moving the app's data folder to another drive (Archive, then delete)
- User-defined Subagents (name, prompt, tools)
- A Theme editor and in-app Theme gallery
- Theming and visual polish: the final token set, extra built-in Themes, final icon artwork, font bundling, general UI polish (a future effort)
