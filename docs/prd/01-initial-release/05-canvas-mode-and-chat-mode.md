# 5. Canvas mode and chat mode

Source: [Canvas mode UX](https://github.com/qodesmith/unimatrix-zero/issues/14) (prototype, variant D), [Canvas engine](https://github.com/qodesmith/unimatrix-zero/issues/19), [ADR 0019](../../adr/0019-canvas-is-a-display-for-the-tree.md).

- **Canvas mode is the app.** One canvas holds exactly one Tree, rendered with React Flow. Two orientations share every feature: **vertical** (top-down, the default; Prompt and Reply as separate equal-width boxes) and **horizontal** (left-to-right; one card per **Exchange**, Prompt as header, Reply as body). The toggle animates Turns to their new positions. Orientation is a global Setting; the canvas toggle is a shortcut to it.
- **Chat mode is a slideout** on the right that opens on the Thread of any clicked Turn, can expand to full screen, and has exactly one Input at the end of the shown Thread. To switch Threads, click another Turn on the canvas; there is no Thread switcher. Sending from the slideout into a Reply that already has a response branches, and the slideout follows the new Branch.
- **Layout and navigation.** Layout comes from the Tree: Turns cannot be dragged, Branches read oldest-first. Scroll pans, pinch or ⌘-scroll zooms. On submit the canvas pans to centre the new Reply, keeps the zoom and does not follow it as it grows. A single-Thread Tree keeps its zoom; the first Branch zooms out just enough to show the whole Tree.
- **Thread highlighting.** The active Thread's path to the root is highlighted; hovering a Turn or typing in an Input highlights that path temporarily (typing wins). With the slideout open, its Thread is the default highlight. Focusing a Thread's leaf Input makes it the active Thread (the sidebar's files follow, any selection clears, the slideout closes, the canvas does not pan).
- **Collapse a Branch.** Any Reply with responses folds and unfolds through its Fork pill ("Fork · N Branches"); the toggled Reply stays put on screen.
- **Grouped controls** at bottom-left: minimap, zoom, orientation toggle, and an attention indicator ("N streaming" / "N failed", click to jump to each).
- **Messages.** Long Prompts and Replies scroll inside a capped height with Show more / Show less (a Setting, on by default). A streaming Reply stays on the newest text unless the user scrolls up. Each Reply shows its Context size badge, with the per-Turn size on hover, and an optional Context size meter (a thin bar toward the Model's limit; a Setting, on by default).
- **Delete** from a Prompt uses a hover overlay with an inline confirmation showing the Turn count and "Deleting frees up to X"; nothing shifts. There is no Undo: "This can't be undone." Deleting rewinds the Provider session so the AI never sees deleted Turns ([ADR 0004](../../adr/0004-app-keeps-provider-session-data.md), amended).
