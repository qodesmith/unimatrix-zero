# 14. Export, Archive and restore

Source: [Exporting and restoring Trees](https://github.com/qodesmith/unimatrix-zero/issues/27), [Export, Archive and Summary entry points](https://github.com/qodesmith/unimatrix-zero/issues/30) (prototype, variant A), [ADR 0011](../../adr/0011-archives-are-their-own-versioned-format.md).

- **Exports are one-way Markdown.** Export Thread (Reply menu): one linear `.md` from the root to that Reply, with a preview, Copy and Save…. Export Tree (Tree menu): **one outline file** (default; Branches as nested headings) or **one file per Thread** (a folder named after the Tree, files `NN - <first words of the leaf Prompt>.md`, depth-first). Content: title and date, Prompts as **You**, Replies by Model, stopped/failed markers in italics, attachments as `📎 filename`, tool calls as one line, changed files by name, Subagents as `<details>`, the System prompt only with "Include System prompt", no thinking. Both dialogs say an Export cannot be restored. Copy as Markdown is in the Reply menu. No raw text or JSON exports.
- **Archives** are the app's own versioned zip of JSON documents plus the files they need: every Turn, attachments by hash, each Workspace's hidden store as a git bundle plus its large-file folder, Provider session data as opaque files. **Archive…** (Tree menu) holds one Tree; **Archive everything…** (Settings → Archive & restore) adds Settings, the System prompt library and user Themes. Never sign-ins or user-supplied values such as MCP tokens; ignored files are not archived. The dialog lists what is inside with sizes and a total, says "sign-ins are never included", and runs the fit check first. Building re-hashes every file. Manual only.
- **Restore** starts from Settings → Archive & restore, dropping an Archive anywhere on the window ("Drop to restore" overlay) or double-clicking the file. The preview, shown before anything is written, groups **Will be added**, **Different from yours** and **Already here, skipped**; each differing Tree gets **Keep mine** / **Use archived** with what each discards; Use archived that deletes Turns gets a delete-style confirmation; "Also use the Settings from this archive" is unticked and shown only for Archive everything files; size and free space are shown and Restore is blocked if it does not fit. Ids are kept. A newer app upgrades older Archives in code; an older app refuses a newer one with "This archive needs a newer version of the app". Linked folders: if the Thread in the folder survives the link stays and the next snapshot records differences as a User edit; otherwise the folder is unlinked with its files untouched; a linked Tree restored elsewhere comes back unlinked and app-owned, and moves to a folder like any other ([§9](./09-workspaces.md)). Restored hidden stores are rebuilt from objects and our own refs only ([ADR 0014](../../adr/0014-electron-security-posture.md)).
