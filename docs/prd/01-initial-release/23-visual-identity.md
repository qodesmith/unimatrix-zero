# 23. Visual identity

Source: [App name, sidebar label and visual identity](https://github.com/qodesmith/unimatrix-zero/issues/33), [Visual identity: default Theme, feel and icon](https://github.com/qodesmith/unimatrix-zero/issues/42) (prototype, direction A).

The default Theme is **"Hearth"**: calm, warm neutral, light and dark sets, mode following the system. Warm off-white and warm greys, one clay accent (`#c2562f` light, `#e07a52` dark) for primary buttons and the active Thread, Prompts in a warm sand tint, soft radius (0.75rem), roomy spacing, Figtree. The icon direction is a clay Prompt card splitting into two Reply cards on a warm tile. Token values are in the prototype's `themes.ts`. Everything beyond this (final token set, extra built-in Themes, final icon artwork, font bundling, polish) is a separate future effort.
