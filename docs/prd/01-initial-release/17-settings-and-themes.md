# 17. Settings and Themes

Source: [Settings and user preferences](https://github.com/qodesmith/unimatrix-zero/issues/22), [ADR 0009](../../adr/0009-themes-are-versioned-token-only-json.md), plus sections added by later tickets.

**Principle.** An option earns a Setting only when reasonable users want either value and the default is known. Visual and behavior Settings are global, never per Tree; anything shaping what the AI does in a Tree lives on the Tree, and Settings holds only the defaults new Trees start from. Everything is stored in SQLite (`settings`, the System prompt library, `themes`). The theme mode is read before the window opens to avoid a flash.

**Text size** runs from 12 to 24 pixels in steps of 2. Beside its control on this page, ⌘+ and ⌘− change it a step at a time, and ⌘0 sets it back to 16. It grows text, not the layout, and it is not Zoom, which scales the canvas alone; the window itself never zooms.

**Deliberately not Settings:** a default Model for new Trees (last-used), a simple/advanced mode, interface language.

**Themes.** A Theme is versioned JSON of token values only (shadcn colors and radius, canvas colors, a Shiki theme name, a font family) with a `light` set, a `dark` set, or both; never CSS. A single-set Theme is used in every mode with the mode control disabled and a note. Missing tokens fall back to the built-in Theme; unknown keys are ignored; invalid files are rejected with a plain-language error. Import a `.json` (pick or drag), export any Theme, and a "Browse themes" link that opens the GitHub Pages gallery in the browser (the app never fetches it). Built-in Themes live in code; all UI styles use tokens only. The default Theme is "Hearth" ([§23](./23-visual-identity.md)).
